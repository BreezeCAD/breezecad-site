modules & libraries

Extend it your way.

Modules teach the program new skills; libraries add ready-made parts: motors, linear guides, steel stock. All free and without app stores — download the file and install it.

The catalog didn’t load. It lives on GitHub: BreezeCAD/registry ↗

how to install

Modules — in Settings → Modules.
Libraries — in the Library window.

Or just drop a .bzmod or .bzlib file onto the program window. Modules work right away, no restart; you can turn them off or remove them in the same place.

for developers

Make your own.

A C or C++ module from the template in five minutes; a library is plain JSON with size tables. Put a breezecad.json passport in your repository and it shows up here. Paid ones are fine too — that’s up to the author.
