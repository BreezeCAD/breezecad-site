Открыть превью

Команды веб-превью BreezeCAD

Отправляйте JSON через кнопку «Команды для ИИ» или выполняйте JavaScript в контексте страницы превью. После загрузки ядра появляется window.BreezeCAD. Команды идут по очереди, меняют открытый документ и обновляют дерево и вид. Ошибка построения возвращается как исключение.

const cad = window.BreezeCAD;
await cad.execute({ command: 'app.new_part' });
const sketch = await cad.execute({
  command: 'sketch.create', plane: 'XY',
  profile: { type: 'rectangle', a: [0, 0], b: [40, 25] }
});
const extrusion = await cad.execute({
  command: 'part.create_feature', type: 'extrude',
  fields: { sketch: sketch.id, distance: '12 mm' }
});
const properties = await cad.execute({ command: 'part.properties' });
// properties.size: [40, 25, 12], properties.volume: 12000
const png = cad.capture();
const bzc = await cad.execute({ command: 'doc.save' }); // ArrayBuffer
app.new_part, app.open
Создать деталь либо открыть { name, bytes }, где bytes — ArrayBuffer с содержимым .bzc, .bza или .bzp. Также можно вызвать cad.openFile(file). Если текущий документ изменён, укажите discard: true после явного согласия пользователя на сброс правок. Сборки открываются для просмотра. Для сборок с деталями используйте .bzp.
sketch.create, sketch.add
Создать эскиз на plane XY, XZ или YZ, на рабочей плоскости workplane по её ID или на плоской грани по номеру face. Можно сразу передать profile. Добавить к эскизу sketch линию или прямоугольник с a, b, либо окружность с center, radius. Значения координат и радиусов в мм. Типы line, rectangle, circle.
part.feature_types, part.feature
Получить типы операций и их поля по умолчанию либо текущие поля операции по id. Имена полей совпадают с форматом .bzc.
part.create_feature, part.edit_feature
Создать операцию с type и fields либо изменить поля операции по id. Строка или число в параметре с expression обновляет выражение. У выдавливания поле operation принимает newBody, join, cut или intersect.
part.tree, assembly.components, part.properties
Дерево, состояние документа, объём, площадь поверхности и габариты.
part.faces, part.edges, part.measure
Списки граней и рёбер со ссылками для операций. Измерение принимает a и b, каждый в виде { face: true, index: f.index } для грани или { face: false, index: e.index } для ребра. Расстояние — в мм, угол — в радианах, когда применимо. После перестроения запросите номера заново.
doc.undo, doc.redo, doc.save
Отмена, повтор правки и получение .bzc в ArrayBuffer. Аргументы не требуются.
view.mesh, cad.capture()
Получить треугольники и отрезки вида либо PNG текущего 3D-кадра как data URL.
